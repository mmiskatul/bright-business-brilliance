# Bright Business Brilliance

Build a Premium Light-Themed Website for This Facebook Business

Create a complete, production-ready, customer-facing website specifically for the business represented by the provided Facebook page.

Use the Facebook page as the primary reference for:

Business name

Logo

Branding

Products

Services

Offers

Contact information

Location

Opening hours

Facebook posts

Customer reviews

Business personality

Existing visual identity

Photography style

Do not invent important business information.

If information is unavailable, create a clean placeholder structure that can easily be replaced with the real information later.

CORE DESIGN DIRECTION

The website must feel like a premium modern business website, designed by a professional UI/UX team.

The visual direction must be:

LIGHT + CLEAN + PREMIUM + MODERN + WARM + TRUSTWORTHY + ELEGANT

VERY IMPORTANT — LIGHT BACKGROUND

The website must NOT use a dark theme.

Do not use:

Black backgrounds

Dark navy backgrounds

Dark charcoal sections

Dark full-screen hero sections

Black cards

Dark dashboard-style layouts

Heavy dark gradients

The overall website should have a bright and airy appearance.

Use a primarily light background such as:

Soft white

Warm white

Off-white

Very light neutral

Subtle cream

Extremely light brand-tinted backgrounds

Example visual direction:

#FFFFFF

#FAFAF8

#F8F9F7

#F6F5F1

Use the actual brand colors from the Facebook page as accent colors, not as heavy backgrounds.

Create a refined light color palette based on the business branding.

Important Rule

Accent colors should enhance the light design.

Do NOT turn the website into a dark website just because the brand has a dark logo or dark colors.

The header should have:

Minimal shadow
